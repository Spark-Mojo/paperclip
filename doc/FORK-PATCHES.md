| 14 | — (new) | SPA-9275 | **Ephemeral worktree per run** (`enableEphemeralWorktreePerRun` experimental flag, default OFF). Today the engine keeps one git worktree per CARD for the card's whole life (168 worktrees / 203 GB on `/srv/bulk/worktrees`, 717 workspaces stuck `cleanup_failed` because teardown `git worktree remove ... || true` fails silently). When the flag is on: `realizeExecutionWorkspace` places the worktree under `${worktreeParentDir}/runs/<runId>/` (NOT `${worktreeParentDir}/<branch>/`); the branch is still template-derived and tracked on the remote; the heartbeat finally block invokes `releaseEphemeralRunWorkspaceForHeartbeatFinally` which (a) pushes the branch to `origin` via the workspace GitRemoteAuthProvider, (b) `git worktree remove --force`, (c) `git worktree prune`, (d) `fs.rm` fallback if removal still fails; the first attempt is retried once after a 200ms backoff; failures are returned (never `|| true`'d); then (e) archives the execution workspace row with `cleanupReason = "ephemeral_run_release"`. New startup reconciliation `reconcileEphemeralWorktreesOnStartup` (called from `server/src/index.ts` on every engine boot) reads `heartbeatRuns.status IN ('queued','running')` for the live-run guard, groups every `git_worktree` execution workspace by `<parent>` + `<repoRoot>`, then runs both `reapOrphanedRunWorktrees` (walks `/runs/<runId>/`, rescues unpushed state to `paperclip/rescue/<runId>/<ts>` before force-removing) and `sweepTerminalIssueRunWorktrees` (finds done/cancelled cards — including the `cleanup_failed` backlog, on BOTH ephemeral and legacy `<parent>/<branch>/` shapes — confirms the branch is pushed (rescue if not), archives the workspace row). Files: `packages/shared/src/types/instance.ts` (new `enableEphemeralWorktreePerRun` flag + `feature-catalog.ts` entry) + `packages/shared/src/validators/instance.ts` + `server/src/services/instance-settings.ts` (normalize the flag in both branches) + `server/src/services/workspace-runtime.ts` (new `releaseRunExecutionWorkspace`, `reapOrphanedRunWorktrees`, `sweepTerminalIssueRunWorktrees`, `releaseRunExecutionWorkspaceForHeartbeat`, `releaseEphemeralRunWorkspaceForHeartbeatFinally`, `reconcileEphemeralWorktreesOnStartup` exports; `realizeExecutionWorkspace` learns `ephemeralLifecycle`, names the dir by run id, force-removes a stale dir on realize-time collision; `RealizedExecutionWorkspace` carries the flag; `mergeExecutionWorkspaceMetadataForPersistence` persists `ephemeralLifecycle` into the workspace row; `resolveGitOwnerRepoRoot` is now exported) + `server/src/services/index.ts` (re-export `reconcileEphemeralWorktreesOnStartup`) + `server/src/services/heartbeat.ts` (pass `ephemeralLifecycle` from the experimental setting, hoist the recorder and GitRemoteAuthProvider into outer scope, capture `ephemeralRunCleanup` (incl. `executionWorkspaceId`) at realize time, call `releaseEphemeralRunWorkspaceForHeartbeatFinally` in the outer finally for terminal-status runs, append a `lifecycle` run event) + `server/src/index.ts` (fire-and-forget startup reconciliation, log if anything was reclaimed).
